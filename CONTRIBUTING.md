# Как помочь проекту

Спасибо, что хотите помочь! Ниже — как собрать программу, проверить изменения и предложить правку.

## Сообщить о проблеме или предложить идею

- Проще всего — кнопка **«Сообщить о проблеме»** в программе (меню «Ещё» → «Помощь»): она сама подставит версии и журнал.
- Или вручную: [новая issue](https://github.com/ryxIbtw/ZapretGUI/issues/new/choose) — есть шаблоны для ошибок и идей.
- Вопросы и обсуждения — в [Discussions](https://github.com/ryxIbtw/ZapretGUI/discussions).
- Если не работает сама стратегия обхода, а не программа, — это к [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube/issues).

## Сборка

Нужна только Windows 10/11: используется компилятор C#, встроенный в .NET Framework 4.x. Ничего ставить не нужно.

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Рядом появятся `ZapretGUI.exe` и `ZapretGUI.exe.sha256`.

Для проверок есть тестовая сборка — без запроса прав администратора и с режимом снимков окон:

```
powershell -ExecutionPolicy Bypass -File build.ps1 -NoAdmin -Out <папка>\test.exe
```

## Проверки

- **Автотесты** логики (подбор, статистика, списки, разбор ответов GitHub и др.):
  ```
  powershell -ExecutionPolicy Bypass -File tests\run-tests.ps1
  ```
  Тесты не трогают ваш обход и настройки программы.
- **Снимки окон** — чтобы посмотреть, как выглядит изменение, без запуска обхода:
  ```
  powershell -STA -ExecutionPolicy Bypass -File tests\snap.ps1 -exe <test.exe> -root <папка zapret> -out shot.png -page main -theme dark
  ```
  Список страниц и параметров — в начале `tests\snap.ps1`.

На GitHub при каждом push и pull request программа собирается и тесты запускаются автоматически.

## Как устроен код

- `src\core` — логика: zapret, проверки сайтов, подбор стратегии, статистика, диагностика, настройки.
- `src\wpf` — интерфейс на WPF, написанный кодом на C# (без XAML-файлов).
- Язык — **C# 5** (компилятор из .NET Framework): нельзя `$"..."`, `?.`, `=>` для свойств и методов.
- Без сторонних библиотек: программа — один небольшой exe.
- Все надписи — на двух языках: `L.T("по-русски", "in English")`.
- Комментарии в коде — по-русски, простыми словами.

## Pull request

1. Сделайте форк и ветку.
2. Соберите программу и запустите автотесты.
3. Для изменений интерфейса приложите снимок «до» и «после».
4. Опишите, что и зачем поменяли, — простыми словами.
