# Список изменений

## Готовится (после 2.4.0)

**Исправления**
- Резервная копия сохраняет все настройки: избранное, заметки, профили, плитки, свои сервисы и другое.
- В переносном режиме журнал, статистика и история подборов тоже лежат рядом с программой.
- Свои сервисы проверяются одновременно, а не по очереди.
- Серый акцент Windows больше не делает программу серой.
- «Тишина в играх» не срабатывает на видео во весь экран.
- Выбор срока хранения статистики не закрывает окно.
- В шапке подписано «zapret v…», чтобы не путать с версией программы.
- На панели несколько предупреждений не теряются: показывается главное и «(и ещё N)».
- «Сообщить о проблеме» из «Справки» прикладывает сведения о системе.

**Настройки и меню**
- Настройки разбиты на вкладки: «Основное», «Обход», «Вид», «Обслуживание».
- Меню «Ещё» по группам.
- Своя горячая клавиша, свой день и время подбора по расписанию.
- Свой цвет — в окне в стиле программы, выбор папки zapret — в современном окне Windows.
- Окно «Что нового» берёт текст из встроенного списка изменений и работает без интернета.

**Обход и стратегии**
- Профиль по сети: дома одна стратегия, в другой сети другая — переключается сам.
- «Вернуть прошлую стратегию» одной кнопкой.
- Автообновление zapret (по желанию) и уведомление о новой версии zapret из трея.
- Проверка файлов zapret: не удалил ли антивирус `winws.exe` или драйвер, с восстановлением.
- Очистка папки `old-strategies` в Корзину.
- Своя стратегия: копия существующей с изменёнными параметрами, не убирается при обновлении zapret.
- Возврат прошлой версии программы.
- Если в Windows нет `curl.exe`, подбор работает упрощённо.

**Проверки и статистика**
- В диагностике: проверка часов, IPv6 и QUIC (UDP) до YouTube; сетевые проверки идут одновременно.
- Свои сервисы — в статистике и в уведомлениях.
- Карта «день недели × час», сравнение стратегий по дням, окно статистики растягивается.
- Сводка за неделю из трея.

**Вид**
- Тема «Высокий контраст» (включается сама, если она включена в Windows), выключатель анимаций.
- Журнал с цветами и сохранением в файл, экран приветствия с новыми подсказками.

**Для проекта**
- Сайт проекта (`docs/index.html` для GitHub Pages), `CONTRIBUTING.md`, файлы для winget.
- Автосборка на GitHub сама создаёт релиз из тега с текстом из этого списка.
- Код логики разбит на части, больше автотестов (36), скрипты снимков и картинок README в `tests`.

## 2.4.0 — 13.11.2026

**Когда обход сломался**
- Уведомление из трея, когда YouTube или Discord перестали открываться, и когда снова заработали. Красная точка на значке в трее при сбое.
- Понятная причина, если `winws.exe` не запустился (нет прав, драйвер заблокирован антивирусом, занят другой программой, ошибка в стратегии).
- Автовосстановление (по желанию): 5 минут не работает — программа сама пробует другие стратегии, сначала избранные.
- Проверка после включения: если сайты не открылись, на панели предложение подобрать стратегию.
- Тихая диагностика при запуске: найденная проблема показывается строкой на панели. Сторож запускает службу zapret, если она установлена, но остановлена.

**Подбор и стратегии**
- При равном результате первой идёт самая быстрая стратегия, равные отмечены «=1».
- Быстрый подбор по 5 лучшим, сравнение двух стратегий, свои сайты для проверки (`utils\targets.txt`).
- Подбор по расписанию (по воскресеньям в 4:00, по желанию) и в фоне — с уведомлением.
- Избранные стратегии (★), заметки к стратегиям, окно «Стратегии», копирование результатов подбора.

**Статистика**
- Пинг на графике, перебои по часам суток, список последних сбоев, сравнение с прошлой неделей.
- Экспорт в CSV, очистка, срок хранения 7, 30 или 90 дней.

**Сайты и списки**
- «Проверить сайт» с добавлением в «Мои домены», добавление сайта из буфера обмена.
- Свои плашки сервисов на панели (до трёх).
- Импорт и экспорт списков, поиск дублей и ошибок.
- Обновление IPSet раз в неделю (по желанию).

**Удобство**
- Горячая клавиша Ctrl+Alt+Z, команды `--on`, `--off`, `--toggle`.
- Профили, обход вместе с программами, тишина в полноэкранных играх, пауза на 15 минут, час или 3 часа.
- Строка об обновлении на панели, автообновление ZapretGUI (по желанию).
- Ярлыки на рабочем столе и в «Пуске», переносной режим (`ZapretGUI.ini`), «Удалить всё».
- Окно открывается там же, где закрыли. В меню трея — стратегии, пауза, подбор, статистика.
- Первый запуск без zapret: программа предлагает скачать его сама.

**Внешний вид и помощь**
- Свой цвет акцента и цвет как в Windows, порядок плиток, выбор кнопок внизу панели, масштаб Ctrl + колесо мыши.
- Значки «?» с пояснениями, окно «Справка», поиск по журналу и фильтр «только проблемы».
- В диагностике — проверка DNS, отчёт в файл, замер скорости YouTube.
- Мини-панель в трее пишет статус понятными словами, управление с клавиатуры (Tab, Enter, пробел).
